

This practice is on regular expressions and widgets in a simple way.


In this data multiple queries are written to learn regex concepts such as:

* Extracting numbers from mixed text
* Getting digits only from the end of a string
* Finding first and last characters
* Matching specific number patterns
* Extracting country codes from phone numbers


Along with this, widgets are created to understand how user input can be taken in notebooks. Different types of widgets are used:

* Combobox to select or type a value
* Dropdown to choose one option
* Multiselect to select multiple options
* Text widget to enter any value

This is mainly for learning and practicing regex and widgets in an easy and practical way.
