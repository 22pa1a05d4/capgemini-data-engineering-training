# PySpark Practice – Data Cleaning

## What I Learned

In this practice, I learned how to clean and prepare raw data using PySpark. I understood how to handle missing values, incorrect data, and inconsistent formats.

---

## What I Did

- Loaded raw CSV datasets  
- Replaced blank and invalid values  
- Filled missing values with default values  
- Converted data types (string to int, date conversion)  
- Removed negative and invalid sales values  
- Standardized text values (like names and cities)  
- Converted and fixed date formats  
- Handled null and inconsistent records  
- Cleaned multiple datasets from different files  

---

## Final Outcome

I learned how to clean messy real-world data and make it ready for analysis using PySpark.
